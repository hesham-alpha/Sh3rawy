# شعراوي — منيو الحلاقة

صفحة موقع عربية بتصميم HTML وCSS وJavaScript. افتح `index.html` مباشرة في المتصفح؛ التنقل بين منيو الحلاقة ومنتجات العناية ومواعيد ومكان التواصل أفقي بالسحب أو أزرار الصفحات، من غير تمرير رأسي.

الصفحات الثلاث داخل العارض الأفقي في `index.html`. ملف `products.html` يحوّل إلى صفحة منتجات العناية داخل العارض. المنتجات والأسعار وبيانات التواصل المعروضة أمثلة قابلة للتعديل.

تبدأ الصفحة بمقدمة 2D مدتها نحو 4 ثوانٍ: المقص والموس يتحركان معًا في خط أفقي، ثم ينفتح نصفا الورقة لأعلى وأسفل بالتزامن مع اختفاء الأدوات وظهور المنيو من المنتصف، ثم تصعد كلمة «شعراوي» أخيرًا إلى موضع الاسم في رأس المنيو. تظهر مرة واحدة في جلسة التصفح، وتحترم إعداد تقليل الحركة. الشعار محفوظ داخل `assets`، وخط Amiri العربي مضمّن محليًا مع ترخيصه داخل `assets/fonts`. الأسعار أمثلة بالجنيه المصري ويمكن تعديلها في بيانات القائمة أسفل ملف HTML.
